# Jev System One (9Router)

Jev System One fornece classificação sub-segundo de alta precisão para orquestração de subagentes e guardrail de execução.

## Especialistas Mapeados
- `designer`: UI/UX, Framer Motion, Tailwind, acessibilidade, mobile-first.
- `architect`: APIs REST/GraphQL, modelagem de banco de dados, arquitetura limpa, performance de backend.
- `secops`: Auditoria OWASP, injeção SQL/XSS, análise de vulnerabilidades, blindagem de autenticação.
- `tester`: Automação E2E (Playwright), suites de integração, reprodução e testes unitários.
- `reviewer`: Code review de PRs, clean code, padrões de código e detecção de regressões.
- `documenter`: Documentação técnica estruturada e diagramas visuais (Mermaid/SVG).
- `explorer`: Diagnóstico rápido de repositórios desconhecidos e busca em código.
- `analyst`: Levantamento de requisitos, quebra em épicos e estórias de usuário.

## Diretrizes de Uso
Ao receber uma solicitação técnica, avalie a intenção e ative imediatamente o especialista correto e suas respectivas skills da matriz.
